## 2. 地面实况:与官方译文的近重复对标

机翻的缺口条目与库内已有官方译文的条目之间存在大量「只差标点/大小写」的**近重复键**
(`Add Host` vs `Add host...`)。这类键语义等价,官方译文即可当地面实况,
不需要人工标注就能量化机翻与官方的差距。

| | 近重复对数 | 完全一致 | 只差标点 | 实质不同 | └ 风格差异 | └ **内容差异** |
|---|---|---|---|---|---|---|
| 德语 | 655 | 429 (65.5%) | 122 (18.6%) | 104 (15.9%) | 8 | **96 = 14.7%** |
| 意语 | 643 | 304 (47.3%) | 141 (21.9%) | 198 (30.8%) | 128 | **70 = 10.9%** |
| 韩语 | 669 | 481 (71.9%) | 85 (12.7%) | 103 (15.4%) | 6 | **97 = 14.5%** |

**内容差异 10.9%–14.5%,三语高度一致。**

> ### 意语「质量差」是我的测量错误,不是译文问题
> 初测意语实质差异 35.8%,远高于德 20.4% / 韩 21.3%,我一度判断意语质量有问题。
> 拆开后发现主因是**连接词风格**:我写 `cluster di datastore`、`Configurazione della sicurezza`,
> 官方写 `cluster datastore`、`Configurazione sicurezza` —— 两种都是合法意大利语,差的是 house style。
> 意语靠冠词/介词承载结构,这类差异天然比德韩多得多(意 128 条 vs 德 8 / 韩 6)。
> 剔除后意语内容差异 **10.9%,反而是三语最低**。
>
> 而且第一版分层脚本还漏了省略形 `dell'/nell'/all'`,把 `Descrizione dell'attività` vs
> `Descrizione attività` 这种纯风格差异也算进了内容差异,让意语又虚高一截。

# 补记(2026-09-04,3.4.44 / 3.4.45)

## 对第 5 节「官方库缺陷」的更正

复核后 **11 条 → 18 条**,且其中一条是我报错的:

- **撤回 `de Kbps → KB/s`。** 库里 `KBps→KB/s`(千字节)、`kbps→kbit/s`、`Kbps→kbit/s` 全部正确,
  不存在这个缺陷。误报源于近重复比对把 `Kbps` 与 `KBps` 大小写折叠成同一个键。
- **新增 `Community Supported` 系列 4 条**,与 `Partner Supported` 是同一错误的孪生实例,原先漏了。
- **多数缺陷不在原报告所列的键上**:那些键存的是本轮机翻的正确值,真正出错的是**大小写不同的
  姊妹键**(`Silence Alert` 大写 A、`Use explicit failover order` 小写)。

18 条已于 3.4.44 修复,裁决记录见 `plugin/i18n/glossary.overrides.{de,it,ko}.json`。
zh-CN / zh-TW 各 1 条占位符缺陷于 3.4.45 修复。

## 方法论:合并后的「自我验证」陷阱

排查「无库内依据队列」时,我按词边界统计各术语的保留率,得到:

```
HCX 100% / VPC 100% / BGP 100% / OSPF 100% / SNAT 100% ...  (三语一致)
```

据此差点扩充 PROTECTED 名单。**但这些数字几乎全部来自我自己合入的 13.5k 条机翻** ——
等于用自己的产出验证自己的产出。剔除 overlay 重算后:

```
HCX / BGP / VPN / OSPF / SNAT / DNAT / TEP / Workbench / Fleet / Canvas  →  官方证据为 0
VPC 1/1 · Edge 2/2 · GPU 15/16                                          →  证据极薄
```

**结论:merge 之后,任何拿 glossary 做的统计都必须先剔除 machine-draft overlay,否则是循环论证。**
`contrib/audit-language.mjs` 已按此修正(A1/A4 对照「glossary 减 overlay」的权威集);
其余 contrib 工具若在合并后使用,同样需要这一步。

## 「无库内依据队列」为何无法机械消解

de 759 / it 778 / ko 740 条。试过三个角度,均不可行:

| 角度 | 结果 |
|---|---|
| 剔除「实词全是专名/标准缩写」的条目 | 仅 36 条(5%) |

| 查官方语料 | VCF 9 官方文档对 de/it/ko **三语均 404,根本未本地化**,不存在可依的权威 |

**只能由母语运维看到真实界面后逐条裁定。** 这批条目已随 machine DRAFT 一起标记
(`source: official+draft`),不阻塞发布,但不应被当作已审校内容。
