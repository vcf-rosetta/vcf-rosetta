简体中文

VCF 9 UI Translator（项目名 vcf-rosetta）是一个纯前端的界面本地化（翻译）扩展。

  • 不收集任何个人信息。 扩展不读取、不存储、不传输用户身份、凭据、浏览历史或页面业务数据。
  • 不向任何服务器发送页面内容。 翻译在浏览器本地完成，词典文件随扩展打包或按需下载到本地后使用。
  • 本地设置。 仅在浏览器本地 / 账号同步存储区（chrome.storage）保存用户偏好：启用开关、界面语言、生效主机白名单、是否开启「未翻译词条采集」。这些数据不发送给作者或第三方。
  • 未翻译词条采集（默认关闭，需用户手动开启）。 开启后，扩展会收集当前页面上「未命中词典的英文界面文本」，仅保存在本设备的浏览器本地存储（chrome.storage.local）中，由用户主动点击「导出」生成 JSON 文件保存到本地，也可随时一键清空。扩展没有任何上传通道 —— 采集结果只能落到本机文件；若愿意反馈给项目，由用户自行把该文件附到 GitHub Issue，扩展不参与。
  • 无远程分析、无广告、无跟踪。

English

VCF 9 UI Translator (project name: vcf-rosetta) is a client-side UI localization (translation) extension.

  • No personal data is collected. It does not read, store, or transmit identity, credentials, browsing history, or business data from pages.
  • No page content is sent to any server. Translation happens locally using dictionary files bundled with the extension or downloaded on demand to the local device.
  • Local settings only are kept in chrome.storage (enable toggle, UI language, host allow-list, optional "collect untranslated strings" flag). They are never sent to the author or third parties.
  • Untranslated-string collection (off by default, user-enabled). When enabled, untranslated English UI strings on the current page are stored only in the browser's local storage (chrome.storage.local) on the user's own device, and are only written to a local JSON file when the user clicks "export"; they can be cleared at any time. The extension has no upload path at all — the collected list can only reach a local file. Sharing it with the project means the user attaching that file to a GitHub issue themselves; the extension plays no part.
  • No remote analytics, ads, or tracking.
